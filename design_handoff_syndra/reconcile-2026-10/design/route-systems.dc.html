Connected systems

The systems outside Syndra it creates and manages accounts on, each joined by an add-on. A short list, usually one row: it exists so a deployment with none still says so, and so each system's state is one look away. Each frame is the real shell and components; open one alone with ?frame= and its name.

Standing rules applied

Cohesion · code owed
