Where a change waits for a person

Every bundle and every automatic rule has its own mode: apply its changes at once, or leave them waiting for you to send. The setting on this page only decides what a new one starts with. Rules show their mode on Automatic rules and in the rule editor. Bundles store a mode but never show it: a new bundle silently takes the default and keeps it. Two ways to put this right are drawn below. A keeps the mode on each bundle and rule and shows it everywhere. B moves the pause onto the roles that deserve one. I recommend B.

Does a rule that waits make sense?

A rule exists so nobody has to give the second role by hand. If every firing waits, the rule becomes a reminder. Waiting earns its place in two cases. The first is a new rule being watched before it is trusted; the code's own comment describes rules watched for a term, then moved to apply at once. The second is a rule that gives something worth a look every time. That second case is about the role, not the rule. Laser cutter · Supervisor deserves a look however it arrives. Front door doesn't, even from a bundle set to wait.

What each path does today

Read from the code, none of these read the setting directly. Bundles and rules follow their own stored mode. A grant by hand always waits in Pending changes, because the form never asks to send. An approved request tries to reach Zitadel at once, and waits only when Zitadel can't be reached or another send is running, without saying so. Four paths behave three ways, and only one of them is visible.

Does changing a mode need a new version?

No. A version records what a bundle gives; a mode is how its changes travel. Switching it changes nobody's access at that moment, so there is no review to read. It is saved on its own, recorded in the audit log with who and when, and shown beside the control. Changes already waiting stay waiting.

One control for the choice

The rule editor already asks "When this rule applies" with a Segmented control and one line explaining the chosen option. Every place that sets this choice uses that pattern, with one real example in the line. It replaces the choice cards drawn yesterday, so there is one pattern for one job.
