# compare-C: Systems, TrueNAS target, Mappings, Storage, Zitadel, Insights, Automation settings, Settings, Mobile

Method: live the live app at 1280x800 (375x812 for mobile) vs boards on localhost:4400. Start view was BASIC; restored to Basic (localStorage `syndra_ui_view=basic`).

Caveats
- localStorage view is shared with the parallel helper, so the view flipped under me several times. I confirmed per page by aria-checked on the radio. Page BODY was identical in Basic and Advanced on Systems and TrueNAS (only the sidebar differs); the boards also draw one body for both views (their toggle changes the sidebar only). Mappings, Zitadel, Insights and Settings were not re-read in Basic.
- Console: no Error / #418 / Minified messages on any page I visited (tool only sees messages from after it attached).
- Pill glitch (low, both): on a full page load the top-bar Basic/Advanced pill highlight paints on Basic for a moment and then slides to Advanced. aria-checked is right. On mobile the first paint shows a "... Home | N places elsewhere need a look" pill, then hydrates into the 4-tab bar.
- Board defect: `route-requests.dc.html` renders blank ("missing ) after argument list"). Line ~71, the `degraded` frame note has unescaped quotes: `("Zitadel didn't answer when it was approved")`. Fixed copy: boards/route-requests-fixedC.dc.html (quotes escaped). Original left untouched.
- Board frame ids are not always `?frame=`: route-zitadel uses `?v=z`, `?v=projects` etc.
- route-login: NOT checked (signed in).
