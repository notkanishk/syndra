## Banner

The README has a commented-out banner block at the very top. To enable it:

1. Add `banner.png` here — 1280×320 works well (2560×640 for retina).
2. Delete the `<!--` / `-->` wrapper around the `<p align="center">` block in
   [`README.md`](../../README.md).

Keep it under ~300 KB. GitHub serves it on every view of the README, and a
heavy banner is the slowest thing on the page.

Both light and dark GitHub themes render behind it, so either commit to a
background of your own or use a transparent PNG that survives both.
